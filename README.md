# PriceWebSearcher

한 화면에서 **물건 최저가**와 **알뜰폰 요금제**를 검색·비교하는 통합 서비스.

- 🛒 **물건 최저가**: 다나와 실시간 크롤링 + 몰별 가격 비교 + 검색어 자동완성 + 찜 + 스마트 추천
- 📱 **알뜰폰 최저가**: 알뜰폰허브·폰비·모요·아요 4개 사이트 즉석 크롤링 + 체계적 필터 + 할인기간 슬라이더
- **API 키·계정 없이** 실데이터로 동작 (공개 크롤링/자동완성 활용)

## 기술 스택

Next.js 16 (App Router) · TypeScript · React 19 · cheerio · fast-xml-parser

## 실행 방법

```bash
npm install          # 최초 1회
npm run dev          # http://localhost:3000  (또는 VS Code에서 F5)
```

- **물건 탭**: 검색어 입력 → 자동완성 → 검색 → "몰별 최저가 보기"
- **알뜰폰 탭**: "가져오기" 클릭 → 4개 사이트 크롤링 → 필터·슬라이더로 조회

### (선택) 쇼핑 공식 API 추가

`.env.local` 파일을 만들고 키를 넣으면 네이버쇼핑·11번가 결과가 함께 나옵니다.
키가 없어도 다나와 실데이터로 정상 동작합니다.

```
NAVER_CLIENT_ID=
NAVER_CLIENT_SECRET=
ELEVENST_API_KEY=
```
